About compression & quality

Smart compression prioritizes visual quality but may change pixels and remove metadata. Choose Lossless to preserve exact PNG data; other formats remain unchanged in that mode. Original formats and dimensions are always kept. The 385 KB target is not guaranteed; larger results are marked and remain downloadable. Animated images and AVIF are retained without lossy re-encoding. Review Smart results before use.

Images are read when selected and kept only for this session. If a file cannot be read, save it locally and select it again. Maximum 64 MB per file and 256 MB per batch.
