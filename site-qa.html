Site QA

Audit the page you are currently viewing without a separate server. Install the Site QA bookmarklet once, open any Webflow site, and run the audit directly inside that page.

Install Site QA

1

Save the bookmarklet

Drag the blue Run Site QA button to your browser bookmarks bar. If dragging is unavailable, use Copy Bookmarklet and create a bookmark manually.

2

Open the site

Visit the Webflow staging or production page you want to review. The audit runs against the rendered DOM of the page you actually have open.

3

Run the audit

Click Run Site QA from your bookmarks bar. A QA panel will appear over the site with findings, filters and export options.

What the browser audit checks

Headings
H1–H6 structure, empty headings, level jumps and hidden headings.
Divitis
DOM node count, div ratio and wrappers that may require manual review.
Images
Alt attributes, linked-image accessible names, HTML width/height, intrinsic and rendered dimensions.
Writing
Duplicate words, punctuation spacing and placeholder copy. Full grammar is not claimed.
Client-First
Class naming heuristics while excluding common Webflow, Finsweet, JS and third-party patterns.
Links & buttons
Missing hrefs, placeholder links, missing anchors and controls that require interaction review.
GSAP
Observable GSAP and ScrollTrigger signals without claiming absence when globals are hidden.
Performance
Basic Navigation Timing, request counts and heavy resources. This is not a Lighthouse score.
Important: this version audits the page and viewport currently open in your browser. It does not automatically crawl an entire site, emulate physical devices, verify every browser, run Lighthouse, or perform a full grammar service. Navigate to another page or breakpoint and run the bookmarklet again to review that state.
